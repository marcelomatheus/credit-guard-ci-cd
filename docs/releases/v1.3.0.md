# v1.3.0

Refresh the CreditGuard interface with a coordinated teal and sage color palette across login, credit simulation, application history and the customer portfolio.

## Interface colors

- Replace the blue accent with deep teal for primary actions, selected profiles, active navigation, focus indicators and links.
- Use pale sage backgrounds and coordinated green neutrals for cards, tables, fields, borders and secondary text in the light theme.
- Give the dark theme deep forest surfaces, mint accents and brighter status indicators, including system-selected dark mode.
- Preserve distinct green, amber and red indicators for approval, manual review and rejection.
- Align the login policy panel, favicon and browser theme colors with the new palette.
- Use shared CSS color tokens for the policy table indicators instead of inline color declarations.

## Delivery

- Set the package and lockfile version to `1.3.0`.
- The merged version bump is selected by the automatic release pipeline, which creates `v1.3.0`, publishes and verifies the Docker image, deploys its digest and publishes these notes with the artifact metadata.
