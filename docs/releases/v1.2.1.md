# v1.2.1

Patch release used to demonstrate the complete delivery flow during the seminar presentation. There are no application behavior changes.

## Delivery flow

- The pull request is linked to an Azure Boards work item with `Fixes AB#<id>`, and the `work-item.yml` check verifies the reference.
- The merge into `main` creates the `v1.2.1` tag, publishes the Docker Hub image, deploys it to the VPS and creates this GitHub Release.
- The `/version` route reports `1.2.1` after the deployment.
